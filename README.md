# Data Science & Analytics Job Market Analysis

## Project Overview

This project analyzes a dataset of data-related job postings
to understand job demand, salary patterns, skill requirements,
and differences between Data Analyst and Data Scientist roles.

## Business Questions

- What does the data-related job market look like?
- How does salary vary across job levels, categories and industries?
- Which skills are most frequently requested?
- Which skills are associated with higher average salaries?
- How do Data Analyst and Data Scientist roles differ?
